	0.5	0.75

Methods of data normalization
1. Simple feature scaling
      - Mathematically, 
             
              x (new) = x (old) / x (max )

      - Result range: 0 to 1


2. Min-Max
      - Mathematically, 
             
              x (new) = x (old) - x (min)  / x (max ) - x (min)

      - Result range: 0 to 1


3. Z-score/ standard score
      - Mathematically, 
             
              x (new) = x (old) - u (mew)  / o (sigma)

      - u : Average of feature        o : Standard deviation
      - Result range: -3 to +3




e.g. df["Length"] = df["Length"] / df["Length"].max()       #simple feature scaaling method

       df["Length"] = (df["Length"] - df["Length"].min()) / (df["Length"].max() - df["Length"].min())       #min-max method

       df["Length"] = (df["Length"] - df["Length"].mean()) / df["Length"].std()     #z - score method

ANOVA - refer slide
- Analysis of Variance
- statistical comparison of groups   -> finding the correlation between the groups

- to analyse we have 2 main parameters
1. F - Test Score
	- ratio of variation between the groups mean over the variation within the same groups
2. p - value
	- checks for the significance




Correlation
- measures to what extent different variables are interdependent
e.g. lung cancer -> smoking

1. Pearson correlation
	Two parameters
	- correlation co-efficient
		- it determines the strength of relationship between the variables
		- Range: -1 to +1
		- Close to +1: large positive relationship
		- Close to -1: large negative relationship
		- Close to 0: No relationship
  
	- p - value
		- it determines the strength and also checks for the significance 
		S. No	Value	Result
		1	<0.001	Strong
		2	<0.05	Moderate
		3	<0.1	Weak
		4	>0.1	No certainty

	
	Strong correlation -> correlation co-efficient = +1 & -1. p - value: <0.001

Linear Regression
- Modelling the relationship from the data

- two types
	1. Simple Linear Regression
	2. Multiple Linear Regression

Simple Linear Regression
-  Independent variable (x1)       -----formulates-----> Linear regression ---------> prediction

predictor (independent) variable = x
target (dependent) variable = y

y = b0 + b1x          where b0 = intercept, b1 = slope

Multiple Linear Regression
- Multiple interdependent variables (x1, ......, xn)         ---------> Linear regression --------> Prediction

predictor (independent) variable = x1, x2, x3, ......
target (dependent) variable = y

y = b0 + b1x1 + b2x2 + b3x3          
where
b0 = intercept
b1 = parameter/co-efficient of x1
b2 = parameter/co-efficient of x2
b3 = parameter/co-efficient of x3

e.g. 
y = b0 + b1x1 + b2x2 + b3x3
y = 1 + 2x1 + 3x2


solution:   
	n	x1	x2	y
	1	0	0	1
	2	0	2	7
	3	1	0	3
	4	3	2	13
